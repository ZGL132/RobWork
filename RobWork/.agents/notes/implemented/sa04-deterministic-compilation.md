# SA-04：权威模型与确定性编译

## Problem

模型输入到运动学真值要经过多段变换（RobotDesign→CanonicalModel→运行时适配）。若变换顺序、浮点格式化、规范化排序不唯一：同一模型在不同会话得到不同身份/摘要——缓存判定失效、证据链对照失去基准（Q3 确定性、NFR-COR-01/02 违约）、评估结果不可复现，"内容寻址身份"（CON-05）从根上不成立。

## Decision

runtime 单元承载确定性编译器（§7.3 三段链）：RobotDesign→CanonicalModel→运行时适配的编译链是**纯函数**——不读隐藏状态、不依赖线程时序、规范化排序无实现定义顺序（如哈希迭代序）；同修订重复编译产物一致（同输入对象集→同输出字节）；基座—世界变换单一不变量在链上唯一点承载。运动学真值唯一（ARC-03），归 runtime（PA-1）。

## Alternatives considered

（事后重构，非当时记录——原决策时文档链未逐项登记备选，2026-10-17 迁移时按决策语境辨识）

1. **直接用框架（RobWork）原生模型＋惰性求值缓存**——否决：原生状态可变、缓存键无法内容寻址，违反 CON-05；真值所有权外溢出 runtime（违反 PA-1）；
2. **规范化模型但允许实现定义排序（哈希迭代序/平台差异）**——否决：排序不稳使摘要在不同平台/版本间不可复现，NFR-COR-02（稳定排序）落空；
3. **纯函数编译链＋规范化排序＋内容寻址**（采纳）。

## Consequences

- 一切影响身份/摘要的环节必须先定义规范化规则（单位换算、浮点格式化、排序键）——每次变更的固定税，换来跨会话可比性；
- 确定性不可行的场景必须显式声明并走证据规则兜底（EVI 正式判定汇总优先级中"确定性不可行"是显式等级，不静默降级）；
- 缓存、增量编译、并行评估可安全依赖摘要相等性（A==B ⟺ 同语义模型）；
- 编译链失败走稳定诊断码与回滚（MDL-06 双编译原子性语境），不产生半更新状态。

## Verification

- ARC-03 验收标准：编译前后 FK/世界轴线一致（三段链自洽性检查）；
- runtime 单元测试套件承载确定性不变量（同输入重复编译字节一致等——具体测试面见 `units/runtime.md` 测试任务节）；
- 执法分级：`context/rule-enforcement.md` §3.1（确定性来源注释要求）＋验收核查。
