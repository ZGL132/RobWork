工业机械臂设计软件用户手册

本手册说明需求工作台的录入、检查、三维浏览与提交操作。产品和组件版本请查看软件内“关于”窗口；手册可离线阅读。

开始使用

  1. 新建或打开项目，切换到“需求”阶段。项目树显示已应用版本，需求面板显示当前草稿。
  2. 使用需求面板的“工位”“区域”“工况”“校验”页签；点选需求树中的条目查看对应属性。折叠的属性组可点标题展开，面板内容较长时可滚动。
  3. 先确定机器人、工具和参考坐标系，再录入空间要求。引用目录以当前项目实际对象为准；对象缺失或引用过期时先处理提示。

界面显示单位随字段标注。长度使用 m 或 mm，角度使用 rad 或 deg；质量为 kg，时间为 s，惯量为 kg·m²。修改显示单位只改变显示，输入转换后的物理量保持不变。

工位与关键任务点

在“工位”页新增、复制、删除工位。复制产生独立条目；被工况、事件或顺序关系引用的工位，须先处理引用再删除。名称用于识别对象，不能用重名覆盖另一个工位。

属性录入与检查
位置与引用选择参考坐标系及默认或命名 TCP，输入 X/Y/Z。位置在选定参考系中表达；引用切换后应核对三维位置与任务意图。
自由度分别设置 X/Y/Z/Roll/Pitch/Yaw 为受约束或自由。容差仅作用于相应要求；不能用不合法数值表示自由分量。
姿态规则固定姿态输入角度；对齐参考系选择对象；对齐几何法向选择特征并核对取反；指向目标输入目标位置；工具滚转自由设置允许角区间。
等级与启用Must 表示必须满足，Should 表示期望满足。关闭条目与删除不同，保留定义以便之后启用。
运动段独立设置接近和撤离段的启用、方向及距离；作业段关联工位操作。参考轴方向与工具轴方向应按任务选择。
顺序按工艺建立顺序键。校验会指出环路、重复前驱或悬空引用；先修正拓扑再正式运行。

“未提供”“未知”“不适用”与数值零含义不同。需要位置但尚未提供时，应通过录入、导入、三维创建或捕获补齐，不能把空值当成原点。

工作区域与采样

  1. 新增 Box 区域，设置中心、三轴尺寸、参考系、TCP 和最低覆盖率。尺寸必须合法；最低覆盖率按界面百分数输入。
  2. 在采样表单选择按数量、按间距或随机采样。随机采样指定数量与种子；相同输入和种子便于复算。
  3. 需要姿态覆盖时设置方向与工具滚转采样数量及范围，查看预计样本数。数量过大或退化定义须先处理提示。
  4. 确认采样表单后生成或更新相应计划。间距采样的计划计数随区域尺寸同步；区域及计划作为一个编辑批次撤销。

未评估的采样网格是几何预览，不表示可达。正式覆盖评估完成后，通过样本清单、状态说明及三维点色检查结果；选中样本可定位到蓝色选中标记。

工况、负载与事件

在“工况”页新增或复制工况，设置启用状态、Must/Should、适用范围和工位清单。必验集合由“启用且 Must”的工况派生；空必验集合的警告应按项目目的确认。

负载包括质量、质心与惯量。质心坐标应与字段指定参考系一致，惯量须物理合法。事件可使用 Grasp、Release、Dwell，绑定存在的工位并填写非负持续时间。最小关节裕量、无碰撞要求和目标节拍属于工程要求；三维几何是否显示不改变这些要求。

CSV、JSON 与批量参数

  1. 从“导入”选择文件。CSV 先核对字段映射与单位，再看换算预览；未知列需要明确映射或忽略。
  2. 按错误清单检查行号、列名、原文和建议。结构错误须修正文件；允许部分导入时，确认前核对保留的正确行。
  3. 确认后才写入草稿；取消不修改草稿。公式样式文本作为数据处理。
  4. 使用“导出副本”写到独立路径。副本不等于应用草稿，不会替代项目的已提交修订。

批量参数表可按字段筛选、修改值或粘贴制表符分隔的数据。确认前核对变更清单；非法值或编辑基线过期时应保留原草稿，重新定位条目后再提交。

生产模板、镜像与阵列

“更多操作”中的生产模板覆盖拣选、机床上下料、码垛、检测、换工具和交接。先设名称前缀、数量及间距，核对实时数量预览后确认。来源详情可查看生成器、批次、关联状态及参数快照。

线性阵列设置方向、数量和间距；矩形阵列独立设置行、列、层及各向间距；圆形阵列设置半径、角度和圆平面法向；折线阵列输入三维控制点。镜像先选择参考系和镜面，核对派生姿态规则。

重生成会检查手工修改冲突；不能以重生成静默覆盖手改。解除关联会保留条目并移除生成关联。批次生成、解除关联和复合参数编辑均可通过局部撤销整体回退。

真实三维视图

  • “三维创建目标”先在场景中放置临时目标，核对位置再确认。取消清除临时预览，不写入草稿。
  • “三维移动选中”操作选中目标，核对预览与属性。坐标/姿态确认后才成为编辑；项目或基线变化时需重新操作。
  • 拾取参考系或几何特征时选择实际对象，核对名称、法向及确认对话框。捕获 TCP 使用当前机器人关节状态的实际末端位姿。
  • 工具栏提供顶、前、右、轴测、缩放、自动缩放、Home，以及线框、透明等显示方式；三维视图也可导出 PNG。
  • Physical、Virtual、Drawable、Collision 与 User 分组控制显示。它们属于会话显示设置，不控制碰撞计算，也不改变任务要求。

校验、工程判定与结果

在“校验”页按级别、层或诊断码筛选，点击对象诊断定位条目，阅读原因和修复建议。就绪检查覆盖引用、位姿、绑定、必验集合、计划、顺序、工具与数据版本。

状态含义与下一步
输入未完成存在缺项或非法输入；先修正定位字段，再正式运行。
可计算 / 计算中满足当前受理前置，或任务正在运行；可计算本身不表示工程可行。
可达 / 弱 / 失败根据结果及诊断检查是否满足硬要求、是否余量不足；不要仅凭三维位置判断。
数据不足缺少所需模型、工具、碰撞证据或其他计算素材；补齐后重算，不能当成通过。
过期结果对应的输入或配置已变化；保留历史结果，使用当前输入重新运行。

部分预览不产生正式证据，不能用于正式可行性结论。正式运行前，任一启用的 Must 条目非法都会阻断就绪。工程策略摘要与显示设置分开；策略未装载或入口提示尚不可用时，不应把显示开关当作计算策略。

草稿、应用与两种撤销

  1. 编辑首先进入需求草稿。按项目保存/草稿保存流程保留未完成录入；重开后检查恢复提示和基线。
  2. “应用草稿”先确认，再校验并生成新的项目修订。取消确认保留草稿，不生成修订。拒绝时阅读原因，修正后重新应用。
  3. 需求面板的“撤销”“重做”作用于局部草稿，不增加项目修订。
  4. 应用后的项目撤销/重做沿项目历史生成新修订；旧修订保持不变。不要将项目撤销与局部草稿撤销混淆。

只读项目允许浏览；编辑、删除和应用受限制。关闭或切换项目时按保存提示处理草稿，旧项目三维预览及过期后台结果不应混入新项目。

常见问题

  • 按钮不可用：检查项目是否打开、是否只读、对象是否选中、输入是否就绪，以及后台是否正在运行。
  • 引用或确认已过期：核对当前项目和修订，重新选择对象并确认，保留原草稿再处理冲突。
  • 粘贴没有内容：核对系统剪贴板内容与权限；不要在未核对变更表前确认批量修改。
  • 三维找不到对象：检查显示分组、相机方向及缩放，使用自动缩放或 Home；隐藏几何不等于关闭碰撞计算。
  • 评估拒绝或数据不足：从状态行和诊断定位缺项。保存错误信息及操作步骤，供复核；不要把未运行当成通过。
  • 手册无法打开：检查安装包是否完整以及系统本地 HTML 默认打开程序；软件内缺失提示与日志提供排查入口。
