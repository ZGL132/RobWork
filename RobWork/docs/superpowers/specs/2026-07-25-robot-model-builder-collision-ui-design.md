# Robot Model Builder Collision UI Design

## Goal

Make collision configuration concise and unambiguous: Drawables render geometry, Collision Models provide collision geometry, and CollisionSetup defines frame pairs excluded from collision checks.

## Data Model

- Remove `DrawableSpec::visualDetail` and `DrawableSpec::collisionModel`.
- Remove `CollisionModelSpec::geometryDetail` and `CollisionModelSpec::source`.
- Keep `CollisionModelSpec::enabled`; disabled models remain in the project but are not emitted to device XML.
- JSON readers ignore removed legacy metadata fields. JSON writers no longer emit them.
- On XML import, every legacy `Drawable` with `colmodel="Enabled"` becomes an independent collision model with matching geometry. Clear the Drawable collision state. Do not add a model when an existing collision model has the same frame, shape, geometry values, file path, and pose.
- Device XML writers no longer emit `colmodel` on Drawables. Only independent `CollisionModel` elements define collision geometry.

## Collision Tab

Replace the separate `Collision Models` and `Collision Setup` tabs with one `Collision` tab.

### Collision Models

The table columns are `Enabled`, `Name`, `RefFrame`, `Shape`, `Size`, `File`, and `Pose`. It retains Add, Remove, and Generate From Drawables actions.

`Drawables` remains a visual-only table. Both visual and collision File cells use a file-picker editor. Both Shape controls use the same option set.

When a collision model selects `STL`, `Mesh`, or `Polytope`, its File value is immediately copied from the best matching Drawable: first same Name, then same RefFrame. Selecting another shape does not overwrite a manually entered File value.

### Collision Rules

The same tab contains Enable CollisionSetup, File, Auto exclude base-first, Auto exclude adjacent joints, and Exclude static pairs controls. The editable pair table is hidden in an `Advanced...` collapsible section.

An `Effective Exclusions` read-only preview refreshes after every rule checkbox change. It shows the base-first and adjacent pairs generated by enabled options, imported or manual enabled pairs, and one `Static pairs excluded` row when static-pair exclusion is enabled.

## Validation and Tests

- Existing XML/JSON tests are updated to assert that removed metadata is absent and disabled collision models are omitted.
- Converter tests cover legacy Drawable collision migration and duplicate suppression.
- Widget-focused tests cover mesh file synchronization where the existing test harness permits it; otherwise the synchronization helper is kept deterministic and covered through model-level tests.
