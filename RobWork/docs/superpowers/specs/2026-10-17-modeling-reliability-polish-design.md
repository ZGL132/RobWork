# 建模模块可靠设计打磨设计

## 目标

让建模模块能够为研发工程师提供可复核、可重放、失败可定位的机械臂设计输入：物性计算不在边界上产生伪通过，DH 转换不因量纲或初值偶然失效，传动矩阵有独立数值证据，导出失败不留下半成功文件，界面明确区分已应用数据、草稿数据和未执行校验。

## 范围与边界

- 只修改 `RobWork/RobWorkStudio/src/rwslibs/industrialrobot/modeling/` 及其测试、建模设计文档和任务留痕。
- 不修改 RobWork/RobWorkStudio 框架源码，不改变跨单元所有权。
- 速度/加速度当前仍按设计文档映射为 `NotProvided`；本批补充清晰提示和测试，不擅自改变 schema 归属。
- 所有新逻辑使用 C++17 和现有诊断/错误语义，先测试后实现。

## 实施方案

1. 惯量特征值：对 `p2==0` 的各向同性有限张量直接返回三重平均特征值，避免 `0/0`；增加各向同性、极小量级、大量级和溢出反例。
2. DH 求解：保留现有确定性 LM 框架，增加显式变量尺度和残差尺度处理；保证收敛状态、残差和 Exact 判定分离，增加混合单位、近奇异、多初值回归。
3. 耦合矩阵：保留生产路径的确定性 Jacobi SVD，测试侧增加独立参考 SVD/QR 对照和阈值附近矩阵，避免同一算法自证。
4. 交接与导出：CanonicalBridge 在 zeroOffset 折叠前检查轴有限且非零；WC/DWC 先写临时文件，全部目标成功后再提交，增加第二面失败时旧文件保持不变的故障测试。
5. 工程师呈现：在模板速度/加速度未进入 runtime schema 的路径上提供明确的状态说明；就绪报告把短路后的层标成“未执行”，DH/物性报告保留误差、来源和参考系信息。

## 验收标准

- 新增回归测试在修复前可证明失败，修复后通过。
- modeling、contract、GUI 测试目标均无失败；GUI 环境跳过必须有明确原因。
- 集成模式 Release 构建和独立冒烟构建成功，`ird_gates` 无新增命中。
- WC/DWC 失败故障注入确认已有输出文件字节不变。
- 变更按工作包独立提交并推送到 `origin/wp13-t23-reliability-polish`。
