# KeyStation 几何与模板能力实施计划

## 目标

在已稳定的 `KeyStation -> CompiledPoseTask` 契约之上，增加几何特征创建、工艺模板、批量生成和快速 IK 预检。所有能力只修改研发需求定义，不复制或维护第二份机器人模型；机器人、Frame、TCP 始终来自当前 WorkCell 与 `RobotModelSpec`。

## 前置条件

- `KeyStation` 语义字段、JSON 兼容和冻结编译器已完成。
- 当前 P2 只把作业位编译为离散运动学任务。
- 接近/撤离只保留规则和 `pathValidationPending`，不声明路径已验证。

## 阶段 G1：3D 工位标记与几何拾取

### 数据与接口

- 在 `KeyStation` 增加稳定的几何引用：WorkCell 几何对象 ID、特征类型、局部参数、解析时的 Frame 指纹。
- 定义 `GeometryFeatureResolver`，将顶点、平面、圆孔/圆柱、边端点和 CAD 面中心解析为位置与局部方向。
- 解析失败必须生成诊断并保留原始意图；不能静默退化为 WORLD XYZ。

### UI

- 在关键工位页增加“基于几何”命令，进入场景拾取模式。
- 场景显示工位名称、坐标轴、姿态箭头和解析状态；选择工位时高亮对应几何。
- 面特征提供工具 Z 正/反法向、边切线与自由滚转等规则，而非默认暴露 RPY。

### 验收

- 工装 Frame 移动后，工位按几何/Frame 重新解析。
- 删除或替换被引用几何时，工位变黄或红并阻止 Must 冻结。
- 固定姿态、法向对齐和自由滚转的 JSON 往返与编译测试通过。

## 阶段 G2：工艺模板与批量生成

### 首批模板

- 料箱取料：料箱 Frame、长宽高、行列层、安全边距、取料高度、工具方向。
- 机床上下料：机床门 Frame、夹具 Frame、待机、接近、作业和撤离规则。
- 码垛：料盘 Frame、角点、层数、层高和放置方向。
- 检测：工件面/孔特征、法向、测量距离和姿态容差。
- 工具换枪与人机交接：接口 Frame、安全方向和必要关节裕度。

### 批量能力

- 复制、关于 Frame 或坐标平面镜像、线性/矩形/圆周阵列、沿曲线等距生成。
- CSV/JSON 导入必须转换为 `KeyStation`，并记录 `Imported` 来源和行号。
- 由模板或阵列生成的工位记录 `templateId` 与参数快照；允许“解除关联后单独编辑”。

### 验收

- 模板参数变化可预览受影响工位，确认后原子更新。
- 批量生成保持唯一 ID，支持撤销，且不会覆盖手工解除关联后的工位。
- 导入错误逐行给出诊断，不创建半有效冻结快照。

## 阶段 G3：快速 IK 预检与结果回写

### 规则

- 预检使用当前 WorkCell 的真实 Device、TCP、碰撞模型和关节限制。
- 结果写入独立的验证记录，包含模型指纹、WorkCell 指纹、时间、求解器配置、可达性、碰撞、关节裕度和可操作度。
- 验证记录绝不反写或替代需求意图；模型/Frame/TCP 指纹变化后自动标记为过期。

### UI

- 支持所选工位和全部工位的快速预检，列表显示绿色、黄色、红色和灰色状态。
- 在属性检查器显示失败原因、可用 IK 解数量和最小关节裕度。
- P2 结构优化只能消费冻结 `CompiledPoseTask`；报告关联预检记录，但仍说明轨迹未启用。

### 验收

- 可达、不可达、碰撞、TCP/Frame 失效和模型变更过期均有自动化测试。
- 所有结果都可导出为审计 JSON，并可由 StructureOptimizer 报告引用。

## 阶段 G4：P3 连续路径验证衔接

- 将 `ApproachRetractRule` 展开为接近段、作业段和撤离段。
- 由 TrajectoryEvaluator 验证连续 IK、关节连续性、路径碰撞、速度/加速度和节拍。
- 需求插件只定义工艺意图和验收阈值；轨迹、动力学和选型评价器以工件契约连接，不把算法写入 UI。

## 不在本计划范围内

- P3 轨迹求解、连续路径碰撞和节拍优化。
- P4 动力学评价与 P5 电机减速器选型。
- 在需求插件中创建第二套机器人尺寸、DH 参数或碰撞模型。
