## 2. 接口变化

## 3. 失败语义

非法数值/单位/维度就地拒绝且保留输入；不可达须确定性证明，搜索未果与缺碰撞证据为数据不足。取消不报错误。过期/跨项目/只读拒绝不得污染结果。失败旧文件保持不变。环境阻碍记 SKIP 或 NOT RUN 并保存日志，不冒充产品通过。

## 4. 生命周期、权威和确定性

修订由 project 管理，模型与名称由 runtime 管理，碰撞/阈值由 policy 管理，单位由 core 管理，命令由 ui 注册。会话姿态与显示单位不写修订、不影响计算身份。运行配置/冻结采样计划按现有 canonical 规则入身份；保持稳定排序、SI、逐轴去重；不另设种子或舍入权威。

## 5. 线程约束

Widgets 仅 UI 线程；耗时任务用 execution，取消/进度须实际可操作。Windows GUI 在 VS x64 环境、windows 平台、绝对路径、同桌面单进程串行运行。新树独立构建，不改写其他工作树产物。
