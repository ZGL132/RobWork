## 首批私有修复设计：F01 区域盒误拒绝、F02 已填参数切单位变义

1. **行为规格**：F01 合法区域盒可实际运行，任一非法分量保留原文并拒绝。F02 输入目标及区域几何后切单位仍代表原物理量，角度/长度分量分别转换，重复切换不以6位呈现精度损失求解精度；非法原文/空缺省保留。
2. **接口变化**：无公共头/端口变化。仅 KinematicsPanelWidget.cpp 解析与显示单位切换，测试 KinematicsAcceptanceGuiTest.cpp、同单元CMake注册。沿用 core 经 DisplayUnitProjection 的换算权威，不写第二份单位常量。
3. **失败语义**：F01 每个分量解析结果显式设置成功标志；首个非法即停止。F02 先暂存全部转换，有限合法值若换算溢出则保持原单位与全部原文，显示修改建议；原文非法本来就不可提交，切换不清零、不丢原文。
4. **生命周期与确定性**：仅 UI 持有的编辑文本与会话显示投影；不改计算结果、修订、配置、采样身份。数字采用 double 往返精度（max_digits10），SI由原单位反算后投新单位。
5. **线程约束**：转换/解析全在 UI 线程，常数个字段；不引入后台对象。
6. **测试矩阵**：合法区域盒实际按钮运行；已填m目标→mm→真IK→独立解析FK对照；非法Y原文保留且合法X正确投影；后续补角度、区域与往返/溢出反例。原有计算、契约、GUI全回归，集成与独立模式。
7. **文档影响**：本节、kinematics增量、矩阵结果和首批红绿证据；不改上游语义。代码前先真实执行新增失败回归。
