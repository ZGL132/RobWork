# 动力学模块审核问题修复实施计划

> **适用范围**：动力学模块 DYN-P1～DYN-P6；不改 RobWork 框架源码，不改变项目存储格式。

**目标：** 接通正式宿主动力学服务、补齐真实三维回放联动、修复峰值通道选择和文案治理，并以真实 Windows Qt 窗口证据关闭审核阻断项。

**架构：** 动力学插件继续只依赖零 Qt 数据契约和服务缝；新增临时关节姿态应用缝，由宿主复用现有 RWStudio State 写入与三维刷新链。回放和峰值定位都先得到同一个 `ReplaySample`，仅在样本完整且宿主姿态应用成功时更新最后有效姿态。正式宿主的曲线、回放、峰值、命令和可用性服务全部在 UI 装配层注入，harness 使用同源 UiText resolver。

**技术栈：** C++17、Qt Widgets、googletest、RobWorkStudio Windows x64。

## 2026-10-22 续修设计与批次边界（WP-17-T11）

1. **行为**：本批关闭可独立验证的呈现问题：空结果禁用定位/回放；曲线与峰值通道同步；反向/绝对峰值标记使用对应样本的有符号曲线值；峰值定位同时更新时刻输入和回放反馈；移动关节单位正确；命令标题显示中文，显示曲线命令切页。保留完整六峰值通道。
2. **接口**：沿用现有装配绑定接口，不新增业务域依赖。新增本单元 GUI 测试目标；harness 消费已经登记的 dynamics→ui 文案资源边，不复制中文表。
3. **失败**：空源、空结果、曲线/回放来源身份不一致、缺关节、重复序号、非有限 q、姿态出口拒绝均不得写姿态，显示原因并保留最后有效姿态；调用方接口异常不静默吞掉。
4. **生命周期**：控件和测试由 Qt 父子树持有，门面生命周期覆盖面板；本批不创建独立结果真值或项目写路径。
5. **线程**：所有界面操作在 UI 线程，计算仍归原计算库；不为启用按钮而在 UI 线程运行 RNEA。
6. **验证**：先执行真实 Windows Qt 控件失败回归，再修改；补装配回读测试及重复/非有限帧测试；跑单元/契约/GUI 与门禁，保存 XML、JSON、窗口截图和日志。GUI 测试只证明控件行为，不替代正式宿主三维实证。
7. **文档**：登记单元卡增量及 WP-17-T11 契约。原审核证据只读，续审结果另建目录。
8. **决策**：无新长期架构决策。用户已要求按推荐方案自动修复，本批不再请求交互选项。

**持续阻断（DYN-P1/P2/P4）**：正式宿主目前没有轨迹生产/归档读取链，trajectory 门面亦未暴露结果源，不能诚实提供当前快照对应的动力学结果。现有姿态桥还以首设备和数组位置映射，缺少结果快照/对象身份校验；本批撤下该不安全写入，保留明确未装配态，待完整执行/身份链一起落位。不得把空闭包当作接通，不得使用 harness 数值替代生产结果。
