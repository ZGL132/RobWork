## 实现盘点不等于交付结论

- 界面代码/流程存在：查到当前控件或命令流程；仍须在与本基线一致的正式程序操作确认。
- 内核存在、入口/供给待核实：算法/服务已写出，但未确认正式宿主中可以完整操作；不能伪造按钮路径，也不能用测试Harness演示代替。
- 需求边界/已知缺口：保留在盘点中，防止被“已实现功能列表”排除；不计作已经交付。没有入口或供给缺失时记BLOCKED并建立问题；观察到实际错误则FAIL。
- 测试辅助：testkit/testkit_qt等服务于验证，不当作终端用户独立菜单功能。

当前必须保留的限制：MA-01网格格式/scale/帧内变换、MA-02正安全距离与完整碰撞链、MA-06导入来源持久、MA-07联合终验、MA-08完整真实视觉及目标文字多重轮廓；另有长表单全矩阵、应用析构压力等未验齐。工作空间采样当前为内联演示/诊断入口，不能声称已提供后台取消；外包络/独立位姿分析内核存在，但正式面板完整入口未核实。

轨迹、动力学、选型、优化虽有面板和内核，正式宿主的数据/执行服务供给须逐项实测。报告/包/方案等也应验证真实执行，不以命令目录已登记代替闭环。新旧分期标签不作为排除已实现能力的理由；未冻结或未实现部分不改写为已完成。
