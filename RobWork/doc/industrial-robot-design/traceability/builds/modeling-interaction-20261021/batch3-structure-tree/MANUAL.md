# 第3批：建模结构树层次与折叠人工验收

分支 wp13-t30；本批基线 b2babf2a95ebc7b8dcedbcee25283c7b8fe45116。仅验本批树导航变化，不代表47项建模功能全部人工通过。请重启软件后测试。

## 1. 启动与准备

1. 保存并关闭其他 RobWork/IRD 窗口，使用验收工程副本。
2. 在 PowerShell 执行上级目录的 `Start-Manual.ps1`。本批程序为 `C:/Users/zgl18/.codex/worktrees/486b/RobWork/build/RobWorkStudio/bin/Release/sdurws_ird_studio.exe`。根 `start_studio.bat` 指向另一工作树，请勿用其检查本批。
3. 在 File 新建或打开项目，从“视图”显示“IRD建模面板”。建模“工具”页点击“从模板新建”，选择通用六轴并确认。
4. 建议先在普通窗口检查一次，再最大化复查。检查的是建模面板内标题为“建模结构”的树。

## 2. 层次及单组折叠

1. 树顶层应只有一个“模型 …”根。根下有基座安装、关节、连杆、工具、场景，以及工作集已有的位姿集或传动对象。
2. “关节”下应有 j1～j6 共6项，“连杆”下应有 base、l1～l6 共7项。初次加载默认展开；工具和场景没有对象时保留空分类。
3. 点击“关节”左侧箭头：仅6个关节子项收起，连杆等其他分类保持原状。再点击箭头恢复。
4. 同样检查“连杆”箭头、模型根箭头。模型根收起后应只剩根行，展开后恢复其下层次。
5. 如已有工具/夹具，检查它们分别位于“工具”与“场景”下。也可通过“编辑→工具管理/场景管理”新增一个验收对象，再看对应分组。

通过：真实父子节点可展开折叠、链序正确、不遗漏对象；分类标题不作为可编辑业务对象，点击分类文字不会把属性编辑目标误换成分类。

## 3. 展开全部与折叠全部

1. 点击树上方“折叠全部”，应仅显示模型根。
2. 点击“展开全部”，模型及所有有子项的分类均展开，对象可访问。
3. 连续交替点击，两按钮应始终可见、可用，树不会出现重复节点或丢失对象。

通过：两个浏览按钮无需进入“更多操作”，不依赖是否有草稿变更；工程处于只读状态时仍可用。

## 4. 刷新与定位

1. 选择 j1，再折叠“关节”。用其他仍可见的连杆进入物性页，执行一次合法编辑或取消，让面板走正常刷新；“关节”应仍折叠。
2. 展开“关节”，选择 j1，核对属性/编辑页对应 j1；再选择连杆，核对对应物性页。
3. 如果工程已应用且三维中有可拾取几何，折叠其所属分类或模型根，再从三维选中该对象。树应展开通向目标的全部祖先并滚动定位。
4. 保持同一对象为选中对象，再折叠其分类，重复从三维定位该对象：仍应展开，不因“已选中”而无响应。
5. 改模型显示名时，身份不变的普通刷新应保留折叠状态。切换另一已保存工程的不同模型根时，应以默认展开状态显示。

通过：普通刷新不擅自展开；显式定位会展开目标；选择继续驱动原编辑页，不串对象、不丢失未确认的同目标表单输入。三维定位前提不满足时标“未执行”，不要当通过。

## 5. 纯浏览不产生修改

1. 在无待提交草稿变更的工程记录当前状态，交替操作折叠、展开、选择与重复定位。
2. 检查没有新增草稿变更、没有新增项目修订，关闭工程不应仅因折叠操作出现保存草稿要求。
3. 本批折叠状态仅在当前面板普通刷新内保持；关闭重开软件不要求记忆上次折叠。

通过：浏览状态不写模型内容，不作为业务撤销/重做项。真实编辑本身产生的变更不属于本项失败。

每项反馈“通过/失败/未执行”，失败附步骤、当前对象及现象。本批交付后暂停，等待人工结果再继续后续修复。
