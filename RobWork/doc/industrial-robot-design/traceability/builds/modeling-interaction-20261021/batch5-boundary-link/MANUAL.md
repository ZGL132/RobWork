# 第5批人工复验：base和末端连杆高亮

1. 关闭旧软件后，用上一级Start-Manual.ps1启动本工作树更新后的程序。根start_studio.bat可能启动其他工作树，不用于本批。
2. 打开上次验收工程，显示“IRD 建模面板”，展开“连杆”。已有正式模型无需为此修复重新应用草稿；本批未改工程数据或存储格式。
3. 点击“连杆1 base”。有已发布可见几何时，对应基座几何应显示工程蓝覆盖高亮，帧原点显示蓝白定位点；没有几何时只能看到原点提示，不能把提示当作实体。相机使用Axiometric/Autozoom确保模型在视野内。
4. 点击一个中间连杆（例如l1），再点击末端连杆（例如l6）。高亮应逐个切换，旧对象恢复原显示；属性目标与结构树一致，关节的蓝白定位点也继续有效。
5. 关闭并重开工程，重复base→中间→末端选择。应无旧高亮残留，单纯选择不会产生草稿修改或新修订。

若出现偏差，保留软件窗口和截图，记录具体树项、是否有正式几何、工程是否已应用；本批交付后暂停等待人工结果，不自行合入主线。
