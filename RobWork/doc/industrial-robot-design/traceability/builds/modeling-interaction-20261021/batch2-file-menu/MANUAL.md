# 第2批：File菜单人工验收

本批以1470247b6为基线，分支wp13-t30。验证本次File菜单提升，不代表其他建模项已人工通过。软件退出后需重新启动才能看到变更。

1. 使用上级目录Start-Manual.ps1启动本工作树正式程序，勿用根start_studio.bat（会打开另一工作树旧程序）。
2. 点击左上角File；应直接看到“新建项目、打开项目、保存草稿、应用草稿、撤销、重做、项目另存为、关闭项目、最近项目”，它们与Exit处于同一层，没有“工业机器人项目”包装层，也没有重复条目。
3. 点击“打开项目”，应出现原打开对话框；取消后回到原工程，取消不改变工程。新建/保存等仍使用原操作流程。
4. 悬停“最近项目”，应展开原最近项目列表；无记录时显示原空态。它只保留自身的第二层，不增加包装层。
5. 打开验收工程，再次查看File：相关命令按原有草稿/撤销/只读上下文启用或禁用；已有项目应用与关闭流程正常。不把无可撤销历史时“撤销”置灰判为菜单缺失。
6. 保存并关闭后重启，确认层级仍正确。按“通过/失败/未执行”反馈步骤与现象。

通过标准：File一次展开即可访问项目命令，与Exit同级；最近项目可展开，原命令行为和禁用规则保持。智能体交付后暂停，等人工反馈。
