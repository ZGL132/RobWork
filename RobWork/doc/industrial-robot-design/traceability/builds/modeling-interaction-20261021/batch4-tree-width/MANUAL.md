# 第4批人工验收：结构树宽度与三维联动

本批程序为当前工作树任务分支wp13-t30的集成Release，不自动合入redesign-main。完整关节分组表单本批仅提供设计，尚未实施；本清单不要求验收未实现的原型。

## 启动和准备

1. 保存并关闭其他RobWork/IRD窗口。同桌面仅一个GUI程序。
2. 在当前仓库运行 `pwsh -NoProfile -File RobWork/doc/industrial-robot-design/traceability/builds/modeling-interaction-20261021/Start-Manual.ps1`。不要使用根start_studio.bat，它指向其他工作树。
3. File → 打开项目，打开已应用且有可见连杆几何的验收工程；也可打开REPORT.md登记的本轮临时验收工程，避免修改自己的工程。
4. 点击左侧“IRD 建模”页签；若隐藏，通过视图菜单恢复“IRD 建模面板”。三维使用View3D → Axiometric，再Autozoom，确保机器人在视野内。

## 操作与通过标准

| 步骤 | 人工操作 | 通过标准 |
| --- | --- | --- |
| 1 | 找到建模面板内部“结构树/属性编辑”之间竖向分隔条。 | 默认树约240逻辑像素，详细编辑区优先分配空间；不是拖整个建模Dock外框。 |
| 2 | 分隔条缓慢往左拖，依次停在约160、80、40像素。 | 可以连续缩窄，不再卡在四百余像素；极窄时文字不可读可拖宽恢复，属于正常呈现边界。 |
| 3 | 将分隔条拖到最左，随后从左边界手柄拖回约240像素。 | 树可完全收起并恢复；对象及选择保持，编辑区空间随之增减。 |
| 4 | 窄栏下拖动底部结构操作条的横向滚动条到两端。 | 新增/删除/上移/下移/六轴重置都能到达；本步只观察，不点击有损按钮；树文字不会随按钮行滚动移走。 |
| 5 | 顶部展开全部/折叠全部（窄时滚动该行），再展开关节、连杆。 | 按钮可达，真实层级正确；只读工程也能展开折叠。 |
| 6 | 依次选择关节j1、j2（键盘上下键也试一次）。 | 属性页对应目标变化，正式三维在同一关节中心显示工程蓝/白心标记；切到j2后j1旧标记消失。标记是屏幕定位提示，不是实体几何。 |
| 7 | 依次选择连杆l1、l2。 | 对应连杆几何显示工程蓝覆盖高亮，中心标记随目标移动；旧连杆恢复原显示。须用有可见几何且已应用的连杆，不能用空连杆作颜色判据。 |
| 8 | 在三维中双击可拾取的连杆几何，然后返回树用键盘换另一对象。 | 树、属性与三维目标一致；选择不会改变项目修订或出现未应用草稿提示。 |
| 9 | 新建尚未应用的对象并选择（仅在临时验收工程尝试，随后撤销草稿编辑）。 | 未有正式对应物时不伪造三维位置，不让上个对象继续显亮；应用草稿成功后才针对正式对象高亮。 |
| 10 | 关闭工程并重开，再试关节与连杆选择。 | 无上个工程残余标记，重开后联动仍有效。 |
