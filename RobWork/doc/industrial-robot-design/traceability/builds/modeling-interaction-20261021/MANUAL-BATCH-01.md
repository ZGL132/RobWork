# 建模交互修复第1批：人工验收步骤

本批基线：redesign-main@04b69c307；实现分支wp13-t30。仅验本批列出的修复；不是47项全部终验。结果由使用者填写，自动测试结果见REPORT.md。

## 0. 启动本批程序

1. 关闭其他RobWork/IRD软件，避免同时操作两个版本。保存原工程，使用专门的验收副本。
2. 在PowerShell执行本目录的 `Start-Manual.ps1`，或右键“使用PowerShell运行”。它会进入VS x64环境并启动本工作树正式程序。
3. 实际程序：`C:/Users/zgl18/.codex/worktrees/486b/RobWork/build/RobWorkStudio/bin/Release/sdurws_ird_studio.exe`。
4. **原仓库根start_studio.bat固定启动D盘主工作树，不包含本批尚未合入的改动。本轮请使用上面的程序。**
5. 新建/打开验收工程，在“视图”菜单显示“IRD建模面板”。建议先将软件窗口调整到约1100×760，再最大化各复测一次。

## 1. 常用入口与滚动（F01/F02）

1. 进入建模面板的“工具”页，不展开“更多操作”。
2. 检查“从模板新建”、URDF导入、Xacro导入、WorkCell导入入口可见。
3. 点击模板新建，选通用六轴并确认；观察结构树6个关节、7个连杆。
4. 选择j1，进入“编辑”；分别滚动属性区和编辑区，找到参数表下方“应用”与确认区。
5. 展开“更多操作”，滚动到“生成占位几何”和导出等命令，再收起。

通过：按钮可见、可点击；上下文禁用时有原因；长表不会把窗口撑出屏幕；能滚动到实际应用与确认按钮，按钮不被其他面板遮挡。

## 2. 树选择切换编辑页（F03）

1. 选择连杆base，确认编辑区出现连杆物性页。
2. 再点j1，确认立即显示关节数值表，而不是仍停物性页。
3. 点“基座安装…”，再从树选择另一个关节j2，确认返回j2关节表。
4. 重新进入基座页，改一个位置并点击该页应用；确认不会无故切回关节页。

通过：显示的编辑对象与树选中一致；同目标刷新不会抢走用户主动打开的页面；不需要反复切页才能继续。

## 3. 表内输入、取消与目标隔离（F04/F06/F07）

1. j1表中将“原点X”输入0.25，按Enter或Tab结束该格，先不要点应用。
2. 立即点“取消/恢复”；确认回到原值。再切页回来，确认0.25没有复活。
3. 连续用Tab填写原点X、Y、Z，每格结束后下一格仍能正常输入，不会突然失去编辑器。
4. 在j1输入未确认值，再选择j2；确认j2显示自己的值。不要把“切到不同对象后保留旧输入”当通过标准。
5. 有条件时记录后台就绪/属性刷新前后：同一对象且权威值未变，尚未确认的数值与错误提示应保留。
6. 输入非法数值再点应用；应就地提示，不能写入草稿或假装成功。

通过：取消有效、旧排队输入不复活；同目标刷新不吞输入；不同目标不串值；表单显示不覆盖领域回填的真实结果。

## 4. 工具安装、多个TCP切换（F04/F08）

1. “编辑→工具管理”，选“新增工具”，局部名称填 `manual_tool`，几何来源先选“无几何”。
2. 勾选“设为默认TCP所属工具”，点“确认写入草稿”。
3. 点“编辑安装与TCP”，在安装接口表“X”输入0.25；依次点该表“应用→确认”，核对回填0.25m。
4. 点“新增TCP”；在新TCP偏移表“TCP Z”输入0.4，点该表“应用→确认”。记下新TCP键。
5. 在TCP下拉框交替选择原TCP和新TCP：原TCP Z应为0，新TCP Z应为0.4，选择后立即刷新，不需要额外点取消/应用。
6. 在新TCP临时输入另一个值，先点取消；确认仍为0.4。临时输入不得自动改变草稿。
7. 输入未提交的TCP显示名，做同目标普通刷新/调整面板后，确认文本没有无故丢失。

通过：下拉项与表中偏移始终一致；安装/TCP分表应用都可达；不把旧TCP显示值写到新TCP。

## 5. 命名位姿切换、暂存与错误（F04/F09）

1. 点“命名位姿→新增”，将条目键改为 `manual_a`，J1构型填0.1，备注填“A”；点“保存条目”。
2. 再新增一条 `manual_b`，J1填0.2，备注填“B”；保存。
3. 下拉框交替选两条，确认选中项不会自动跳回旧项，构型和备注与条目对应。
4. 在当前条目填尚未保存的备注和构型，执行同目标普通刷新/调整面板，检查输入仍可继续。
5. 将构型某格输入“abc”，备注改为“不得保存”，然后直接点“保存条目”。
6. 确认就地提示构型非法，草稿没有保存这条备注；先修正数值再保存才生效。

通过：选项、构型、备注对应正确；非法构型阻止整条保存；取消/未保存输入没有制造项目修订。

## 6. 可见占位网格与项目级应用（F05）

建议另建干净验收工程做本项，避免工具缺物性等其他就绪问题干扰。

1. 从通用六轴模板起步，先选base，在“工具→更多操作→生成占位几何”执行一次。
2. 模板关节原点默认重合：应得到“原点重合/请补XYZ或挂接真实网格”的中文提示，软件不崩溃，草稿不增加半条几何。
3. 选择j1，在关节表中设原点X=0.10m、Z=0.15m，Y=0；点该表“应用→确认”。
4. 选回base，再执行“生成占位几何”；应提示“已生成并登记资源”。属性区应有网格引用，不再提示“未入资源清单”。
5. 执行**项目级“应用草稿”**，确认并观察正式三维。必要时使用适配/标准视图找到模型。
6. 正确结果是一个连接base原点到j1原点的圆柱：中心(0.05,0,0.075)m，长度约0.18028m，半径0.05m（既有占位半径默认值）。
7. 再选j2…j6，分别输入同样的非零原点并应用表单；对应选l1…l5生成占位网格。每段生成后再统一项目级应用。
8. 切换地面、倒挂、壁装，各执行基座页应用及项目级应用，观察整条链随基座安装变化；世界系对象不应随机器人被错误二次旋转。
9. 保存工程、关闭工程、重新打开，确认网格仍显示。占位网格只是辅助外形，不能当真实CAD或惯量输入；目前按Recorded外部资源记录在本机持久缓存，未固化前请勿删除缓存或认为工程已独立携带网格。

通过：零长度拒绝可理解；正常段有真实网格、可提交，端点与关节位置相符；重开仍有网格；没有仅坐标架/选择框却声称几何正确的情况。
