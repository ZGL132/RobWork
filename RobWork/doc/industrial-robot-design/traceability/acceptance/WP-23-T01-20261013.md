## 2. P95 插值定义与样本量口径复算（ask 第 2 项）

- 文档公式（performance-baseline.md:83）：升序排列，h＝(n−1)×0.95，P95＝x⌊h⌋＋(h−⌊h⌋)×(x⌊h⌋+1−x⌊h⌋)——即标准线性插值分位数（h=(n−1)p 约定）。
- **亲跑复算**（pwsh 脚本，等差样本 100·i）：n=15 → P95=1430（h=13.3，x13=1400 与 x14=1500 间插值 ✓）；n=16 → 1525（h=14.25 ✓）；n=21 → 2000（h=19 整数退化 ✓）；n=30 → 2855（h=27.55 ✓）。四点全部与公式吻合。
- **越界分析**：h=(n−1)×0.95 ≤ n−1 对任意 n≥1 恒成立；h 为整数时 ⌊h⌋+1 ≤ n−1。唯一字面越界点 n=1（x[1] 不存在但系数为 0）——有效样本下限 ≥15 杜绝该情形，实际无影响；防御式实现以 hi=min(⌈h⌉, n−1) 即可（观察 O-2）。
- **样本量口径自洽**：每组有效样本 ≥15＋两组合计 ≥30 与 PM-16 原文（:370）一致；"剔除预热 ⇒ 实际执行 ≥16"为正确推论；P95 类基准（B-01/B-04）与中位吞吐（B-06）统计口径区分登记（§2 防混淆段），互不替代 ✓。
- **结论：插值定义数学自洽、样本量口径自洽（ask 第 2 项 PASS）。**
