## 4. F-546 定性独立核验（对抗声明 4——「首应用名解析结构性不可达」）

**四环代码链逐行核实**（本会话亲手审读，modeling/policy/ui 三单元只读）：

2. **不猜测原则**：policy/src/JointLimits.cpp:326-337——`names.tryRuntimeName(spec.jointObject)` nullopt 即推 CllNameUnresolved（kCodeNameUnresolved＝PolicyDiagCode::CllNameUnresolved 注册码）诊断并 `return out`（status=Failed，finalized=false——ARC-04 不猜测的忠实执行）。
3. **评估未终态化映射**：modeling/src/CommandHandlers.cpp:325-333——`evaluation.status != Completed || !finalized` → `TravelEvaluation::EvaluationFailed`（诊断透传、不静默放行）。
4. **硬断言拒绝**：同文件 :1129-1135——EvaluationFailed → `project::PrepareOutcome::RejectedHardAssert`（「行程校验未执行＝不静默跳过」）。

**测试三角**（区分「hard-assert-failed 确为名解析墙」与「其他 hard-assert 源未排除」）：
