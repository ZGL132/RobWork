## 发现与转登

- **建议级 S-1（转登 findings）**：`IWorkbenchContent` 新增纯虚 `commandRegistry()` 属公共接口的**破坏性面增量**（任何库外实现类——现状仅库内 WorkbenchContentImpl——在升级时必须同步实现）。当前外部实现类为零（IWorkbenchContent 实现封闭在库内），故实际零破坏；建议后续治理修订考虑"访问器增量以非纯虚＋默认实现"或接口版本化措辞，属长期接口治理建议。→ F-418
- **建议级 S-2（转登 findings）**：验收段 GUI 测试需要 `QT_QPA_PLATFORM=windows`＋`QT_PLUGIN_PATH=<Qt>/plugins` 环境前置（冒烟树 platforms 插件不被 POST_BUILD 复制）——该前置此前任务以宿主 GUI 冒烟 README 形式登记过（F-320 家族），本任务在同一口径复用，建议随 gate-all.ps1 的 GUI 步骤统一内化。→ F-419
