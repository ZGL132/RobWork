## 2. 对抗性核查补充

- **下拉整合的 registry 面**：『导入 ▾』仅呈现层合并——ui CommandRegistry 九命令目录/enablement/提交出口全部零变化；冒烟 harness 以 menu-action-via-uitext＋import-dropdown-present/disabled 三断言钉住（无项目态＝动作全禁＋本体置灰，与九键一致）。gui 用例断言菜单恰两动作且独立按钮不复存在。
- **空态语义**：新增键不依赖选择（UI-T30 空集合起步语义保持——本批实为恢复被统一禁用误伤的新增可达性）；复制/删除按页内选择面独立判定（点工位不动区域页状态——三选择锚成员互相独立）；无会话/只读＝全禁（UI-T30 诚实态优先级更高，选择面判定仅在有会话时到达）。
- **isVisibleTo 断言口径**：非激活页签子树 isVisible 恒 false（Qt 容器可见性）——测试以 isVisibleTo(parent) 断言自身显隐态；激活页（工位）的真实可见性另断。这是本批测试适配的机制性发现（已注释在用例内）。
- **变异③恒等变换实录**：首稿 `false || X` 未改变语义（翻红失败）——识别后重写为 `const bool isImport = false` 真旁路后翻红。变异验证的价值恰在于此：变异无效 ≠ 测试无效；记录在案防复犯。
- **卡片折叠的会话态边界**：折叠状态随控件生命周期（构造期一次构建不随重投影重建）——刷新后保持；不入修订不入项目文件（纯呈现态，与 UI-T37 既定呈现纪律一致）。
