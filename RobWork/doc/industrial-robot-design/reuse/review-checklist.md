# 上游复用审查清单

- [ ] 按 policy §1.2 核查实际需求与整体收益：未为复用数量接入无需求能力；已适配路径核查后保留；产品业务职责及独立oracle边界明确；通用工具比较语义/安全/依赖/转换与维护成本，后置不当豁免，不以成本为由保留平行核心或绕过缺口批准。
- [ ] 每个迁移能力包执行 policy §1.1：实施前在任务/迁移说明中写明具体保留/删除/适配/职责归属，需求、上游适用证据与必要公共兼容明确；不强保旧内部结构，不为复用降需求或扩大重构范围。
- [ ] 独验核对准确性、架构、简洁性及运行效果四维证据：独立正确性验证、唯一权威与依赖方向、冗余删除/必要保留理由，以及性能/确定性/资源/错误行为；无验收依据的退化不得自判可接受。仅有上游调用、复用数量或减行数不通过。
- [ ] 从根 AGENTS.md §0.1、ARCHITECTURE §3.6 / SA-19、policy 和 migration §11 核对阶段准入；原 GOV-T21 pass 不自动覆盖新增门禁。
- [ ] 审计覆盖全部 20 单元的真实功能/调用链，含 inline/template/helper、测试、生成器、脚本、工具及构建；16 个重复文件不是范围，existing-adapter 不自动合规。
- [ ] functions/<unit>.json 按 audit-contract.md §4 记录需求/AT、入口、符号/摘要、候选、权限、差异和结项；无整目录 business-specific 豁免。
- [ ] catalog 上游文件/全限定符号/目标/版本/摘要及测试/示例/文档可核查；ownerUnit、usageRole、操作与权限引用明确，不与 L1—L5 混淆；能力状态不替代功能适用性。
- [ ] 权限先于复用：值类型、受控视图、任务私有 State/solver/engine、宿主精确例外分别审查；load/clone/factory/结构写入及句柄逃逸均覆盖。runtime 保持模型/名称 owner，policy 保持策略/碰撞权威。
- [ ] 宿主例外无扩散，worker 不跨进程传指针/借持句柄、不链 Widgets；按同一 runtime 规则物化。
- [ ] evidence 的 EvaluationOutput/aggregateVerdict/ResultEnvelope 与 diagnostics 稳定码/文案及 core 数据契约沿用，无自造 envelope、码表或当前性语义。
- [ ] direct/adapter 均证明业务入口调用上游并实际消费返回值，同模型/State 上游对照、独立 oracle 及隔离断开/扰动实验有效；include/link/演示函数不构成证据。
- [ ] 源码、上游、依赖/配置及测试版本变化触发相关证据重验；普通局部修改不无条件跑全量实验。
- [ ] changes/<taskId>.json 精确覆盖所有修改/新增/删除的产品源码、测试、CMake，摘要匹配；未引入平行模型/算法、复制粘贴内核或改名规避扫描。
- [ ] extension/new-core 必须有完整缺口提案与所有者明确批准，批准引用和提案摘要匹配；不能实施者自签，也不能用本治理授权替代算法授权。
- [ ] 业务端口、DTO、稳定诊断、可信度、工况覆盖、排序/去重保留；接口不兼容明确版本化；无 Qt/互链/跨私有头/名称拼接/快照写入。
- [ ] 核查坐标系、单位、offset、参考点、DOF/Body 对应、惯量基准、工具/载荷/摩擦/重力只计一次和线程/所有权；中文注释解释原因。
- [ ] 复用迁移按能力及影响范围具备真实上游调用、独立解析 oracle、端口集成、回归、必要性能/打包及双模式日志；passed/skipped/failed 分列，必需测试跳过不能当通过。
- [ ] 优先直接 API、上游模型/夹具/工具/测试/导出目标；不建全库 facade、第二模型层、通用 backend 或每个数学操作一个 DTO。共享 Eigen 不直接等同重复算法。
- [ ] 同能力批次删除替代核心、死代码/依赖和静默旧兜底；独立 oracle 限测试使用；不改基线/删库存洗白。
- [ ] 按影响运行相关检查；门禁补强须有 audit-contract §7 的真实正负夹具，最终交付额外 RequireMigrationComplete 及语义关闭证据。新增门禁未实现/验收不得标通过；普通文档维护无需产品构建。
- [ ] 复用迁移由独立会话绑定确切 SHA 验收；报告与记录可追溯，实施者不得自行合入 redesign-main，main 不变。

机器门禁现状和待实现补强见 audit-contract.md；语义与批准真实性审查不可省略。历史库存是待消除事实，不是永久白名单。普通文档维护只做文档门禁和事实/链接核对，产品变更才提交逐文件产品凭证。
