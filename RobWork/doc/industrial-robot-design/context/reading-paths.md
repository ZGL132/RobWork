# 按任务定位上下文（可选参考）

根 AGENTS.md §1 是默认入口；本文仅在不知从哪找时取用。任务契约已有 unit/requirements/designRefs/verify 字段，不增同义字段。

| 当前问题 | 定向读取 |
| --- | --- |
| 算法/复用 | 需求对应条目、单元相关接口、上游实际符号、reuse 相关能力与文件条目 |
| Qt 功能 | 对应 ui/业务单元章节、实际生产接线、ird-qt-gui-windows 的操作段 |
| 持久化 | 对应 project/io 的数据格式、事务及失败语义、实际读写代码 |
| 治理脚本 | 被改规则的权威条款、脚本相关函数及其调用点 |
| 测试故障 | 失败用例与日志、被测函数；确有环境问题再查 DLL/GUI 操作技能 |
| 独立验收 | ACC 适用项、送验 SHA、相关契约及证据路径 |
| 自动排队/tick | PIPE 对应阶段、state.json 本体；人工任务不读 |

需要任务时用任务 ID 搜索 tasks/（含 foundation/）；只取当前契约与实际前置。不要为找一个任务通读全部任务 JSON、DTB、资产地图或历史证据。

复用库存由门禁全量检查；人工上下文只取变动路径对应条目。新核心/上游扩展仍须先提案获明确批准，迁移前治理独立验收阶段门不变。
