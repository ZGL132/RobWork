- **最小实现：**追加式仓库＋接纳校验＋当前性索引＋查询；缓存命中规则按 architecture/execution-model.md §3（仅完整 `sliceHash`；Partial/Failed/Canceled/Interrupted 与不兼容版本不得命中正式缓存）。
- **正常/边界/失败测试：**
