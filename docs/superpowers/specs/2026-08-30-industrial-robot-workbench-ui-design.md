# 工业机械臂混合式工程工作台界面设计规范

> 日期：2026-08-30
>
> 状态：已完成方案确认并写入产品文档
>
> 适用范围：RobWorkStudio 工业机械臂研发工作流
>
> 目标分辨率：1920×1080，Windows 100%～150% 缩放

## 1. 设计目标

本方案把工业机械臂的建模、需求、运动学、轨迹、动力学、选型与联合分层优化组织为一套连续的研发工程工作台，并保持与 RobWorkStudio 主窗口、插件 Dock 机制和原生三维视图兼容。

界面遵循以下原则：

1. 原生三维视图始终位于主窗口中央，不被业务页面替换。
2. 高频操作直接可见，低频参数统一进入“高级设置”或“更多”。
3. 使用工程师能直接理解的名称，不显示哈希值、内部对象标识、缓存、Schema、冻结、运行编号等实现信息。
4. 编辑、预览、计算、采用结果相互分离；预览和播放不修改方案。
5. 表格、三维对象、属性面板保持同步选中。
6. 每个阶段只呈现当前工作所需的控件，避免重复维护上游数据。
7. 快速检查用于交互反馈，正式计算用于评审和报告；两者的用途和结果状态必须明确。

## 3. 主窗口框架

### 3.1 固定结构

RobWorkStudio 原生菜单栏和工具栏保持可用，新增工业机械臂工作流工具栏。窗口分区如下：

```text
┌────────────────────────────────────────────────────────────────────────────┐
│ 菜单栏：文件  编辑  视图  工具  帮助                                    │
├────────────────────────────────────────────────────────────────────────────┤
│ 项目 ▾ │ 建模 │ 需求 │ 运动学 │ 轨迹 │ 动力学 │ 选型 │ 优化 │ 状态 │操作│
├──────────────┬──────────────────────────────────────┬──────────────────────┤
│ 当前阶段     │                                      │ 对象属性 / 点动       │
│ 业务 Dock    │         RobWorkStudio 三维视图       │ 工程设置 / 场景显示   │
│              │                                      │                      │
├──────────────┴──────────────────────────────────────┴──────────────────────┤
│ 阶段结果 / 曲线 / 任务 / 诊断 / 计算依据 / 日志                          │
├────────────────────────────────────────────────────────────────────────────┤
│ 项目 │ 方案版本 │ 结果状态 │ 当前任务 │ 单位 │ 简短消息                  │
└────────────────────────────────────────────────────────────────────────────┘
```

中央区域始终使用 RobWorkStudio 原生三维视图。工业机械臂功能以可移动、可隐藏、可浮动的 Dock 接入，不接管其他 RobWorkStudio 插件的 Dock。

### 3.2 Dock 分区

| 区域 | 默认内容 | 行为 |
|---|---|---|
| 左侧 | 建模、需求、运动学、轨迹、动力学、选型、优化 | 七个阶段 Dock 互相标签化；阶段按钮抬升对应 Dock |
| 右侧 | 对象属性、点动、工程设置、场景显示 | 可标签化或并排；对象属性跟随当前选中项 |
| 底部 | 阶段结果、曲线、任务、诊断、计算依据、日志 | 当前阶段自动抬升主要结果页；不隐藏后台任务和错误 |

默认宽高：100% 缩放时左侧 440 px、右侧 320 px、底部 280 px；125% 缩放时左侧 380 px、右侧 300 px；150% 缩放时右侧与左侧标签化，底部 240 px。中央三维视图逻辑尺寸不得小于 640×480，Dock 最小宽度为 320 px。

布局由 Qt 高 DPI 机制缩放，不自行二次缩放字体和图标。用户可保存布局；“恢复工业默认布局”只恢复本工作流 Dock，不重置其他插件布局。浮动 Dock 若落在当前屏幕之外，启动时移回主屏幕可见区域。

### 3.3 阶段工具栏

左侧为项目下拉菜单，中间为七阶段入口，右侧为公共操作：

- 项目：新建、打开、保存、另存为、关闭、最近项目。
- 阶段：建模、需求、运动学、轨迹、动力学、选型、优化。
- 公共操作：撤销、重做、应用更改、运行、取消、更多。
- 阶段状态：输入未完成、可计算、计算中、结果有效、需重算、依据不足、计算失败、不可行。

按钮状态：

| 操作 | 启用条件 | 运行中行为 |
|---|---|---|
| 撤销/重做 | 当前方案存在对应历史 | 计算期间仍可用，但会使在算结果标记为需重算 |
| 应用更改 | 当前页有合法且未应用的编辑 | 禁用，避免同一任务输入变化 |
| 运行 | 输入完整、无阻断问题且没有互斥任务 | 变为禁用，取消启用 |
| 取消 | 当前阶段存在可取消任务 | 点击后显示“正在取消”并防止重复点击 |
| 更多 | 当前阶段存在低频操作 | 运行中只保留安全的只读操作 |

### 3.4 公共交互语义

编辑流程统一为：编辑草稿 → 行内校验 → 应用更改 → 形成一个新方案版本。一次“应用更改”只形成一个版本。任何三维预览、候选查看、点动、轨迹播放均为场景操作，不改变方案。

结果状态使用面向工程师的短文本：

| 状态 | 含义 | 主要操作 |
|---|---|---|
| 输入未完成 | 必要输入缺失 | 定位缺项 |
| 可计算 | 输入完整且校验通过 | 运行 |
| 计算中 | 任务执行中 | 取消、查看任务 |
| 结果有效 | 结果对应当前方案和设置 | 查看、比较、报告 |
| 需重算 | 方案或设置已变化 | 重新运行 |
| 依据不足 | 快速检查或输入可信度不足 | 正式计算、补充输入 |
| 计算失败 | 任务未完成 | 重试、查看详情 |
| 不可行 | 计算完成但未找到满足约束的结果 | 查看约束与淘汰原因 |

计算方式显示为“快速检查”和“正式计算”。用户可见的计算依据只显示方案版本、计算方式、主要设置、时间和结论，不显示内部标识。

## 4. 项目入口与新建项目

### 4.1 无项目空态

```text
┌────────────────────────────── 三维视图 ──────────────────────────────┐
│                                                                      │
│                         工业机械臂工作台                             │
│                    [ 新建项目 ]  [ 打开项目 ]                        │
│                                                                      │
│ 最近项目                                                             │
│  · 装配机器人方案                                                    │
│  · 上下料机器人方案                                                  │
└──────────────────────────────────────────────────────────────────────┘
```

没有项目时，阶段入口禁用，只保留新建、打开和最近项目。

### 4.2 新建项目向导

向导分三步：

1. 项目信息：项目名称、保存位置、说明。
2. 初始来源：从模板、从 URDF、空白项目。
3. 创建确认：机器人名称、主运动链、资源处理和保存位置摘要。

从 URDF 新建时显示：URDF 文件、机器人名称、主链起点、主链终点、目标运动链、连续关节范围、资源复制方式。问题直接显示在对应字段下，不提供独立“模型检查”页面。创建失败不得留下半成品项目；创建成功后直接进入建模阶段。

URDF 只在主界面的新建项目流程中使用。建模页面不得提供 URDF 导入、模型导入、导入报告或独立模型检查功能。

## 5. 建模界面

### 5.1 页面结构

一级分区为结构、几何、物性、工具、环境。左侧显示机器人树，右侧“对象属性”编辑当前对象，底部提供参数表、几何表、关节能力、命名姿态、转换分析和诊断。

```text
┌──────── 建模 ────────┬──────────── 三维视图 ────────────┬── 对象属性 ──┐
│ 结构 几何 物性 工具  │                                   │ 名称/类型     │
│ 环境                  │                                   │ 位姿/参数     │
│ ├─机器人              │                                   │ 限位/物性     │
│ │ ├─基座              │                                   │ [应用更改]    │
│ │ ├─关节1             │                                   │               │
│ │ └─法兰/TCP          │                                   │               │
├───────────────────────┴───────────────────────────────────┴───────────────┤
│ 参数表 │ 几何表 │ 关节能力 │ 命名姿态 │ 转换分析 │ 诊断                  │
└───────────────────────────────────────────────────────────────────────────┘
```

### 5.2 结构与表格

机器人字段：名称、自由度、参数化方式、基座、法兰、默认 TCP、Home、Zero。关节字段：名称、类型、父对象、子对象、原点位姿、轴向、下限、上限、Home、Zero。高级设置：速度上限、加速度上限、最大转矩或推力、数据来源、备注。标准 DH 参数按适用关节显示。

结构表列：序号、名称、类型、父对象、关键参数、轴向、下限、上限、Home、状态。操作：新增关节、固定坐标系、上移、下移、复制、删除、参数转换。

### 5.3 几何、物性、工具与环境

- 几何分为显示几何和碰撞几何。表列：对象、用途、几何类型、来源、位姿、尺寸、显示、状态。可由显示几何生成碰撞几何并保持关联。碰撞排除关系放入高级设置，并使用公共碰撞策略。
- 关节能力表列：关节、行程、速度、加速度、转矩或推力、来源、状态。
- 命名姿态表列：名称、关节值摘要、用途、状态；操作为记录当前姿态、设为 Home、预览、删除。
- 物性表列：部件、质量、质心、惯量、来源、状态；支持估算、用户填写、测量值和外部数据。
- 工具与 TCP 表列：工具、TCP、负载、启用、状态；支持新增工具、记录 TCP、设为默认、预览。
- 环境坐标系表列：名称、父对象、位姿、用途、状态。环境几何表列：名称、类型、位姿、碰撞参与、显示、状态。

校验在编辑和应用更改时自动进行。字段错误就地显示，跨对象问题进入诊断面板。页面不显示原始 XML、输出路径或内部名称。

## 6. 需求界面

一级分区为工位、区域、工艺、负载。常用操作为新增、记录 TCP、拾取、创建和更多。

关键工位字段：名称、工艺类型、必须/建议、参考坐标系、TCP、目标位置、姿态规则、约束轴、位置容差、角度容差、接近距离、工作距离、退出距离、停留时间。姿态规则包括固定姿态、对齐坐标系、对齐几何法向、指向目标；约束轴为 X、Y、Z、R、P、Y。

常用工艺类型：通用、拾取、放置、上料、下料、检测、安全待机。焊接起点、焊接终点、换刀、交接放在“更多”。创建菜单提供模板、阵列、镜像、复制；模板包含拾取放置、机床上下料、检测和安全待机。

工位表默认列：序号、名称、工艺、等级、参考系、TCP、位置容差、角度容差、状态。详细列可选显示位置、姿态规则、接近/工作/退出距离和停留时间。

区域字段：名称、形状、参考坐标系、中心、尺寸、方向、覆盖要求、采样方式、状态。默认使用中心和尺寸；最小/最大边界、各轴样本数或间距辅助放入高级设置。区域表列：名称、形状、范围摘要、采样数、覆盖要求、状态。

工艺表列：工艺段、起点、终点、方式、速度要求、节拍要求、状态。负载工况表列：名称、质量、质心、惯量、适用工位、状态。

项目验收摘要直接显示并可行内编辑：目标节拍、最小关节裕量、碰撞要求、障碍物要求和默认设置。必须项缺失时阻止正式计算，建议项缺失时给出警告。支持 CSV 和受支持需求文件的导入导出，但不向用户暴露发布或冻结类操作。

## 7. 运动学界面

提供“姿态诊断”“任务验证”“能力探索”三个模式。页面直接使用当前项目模型、需求和公共工程设置，不重复提供模型绑定、需求副本或本地阈值。

- 姿态诊断：当前 TCP、姿态状态、最小关节裕量、奇异性提示；关节表列为关节、当前值、下限、上限、裕量、状态。雅可比详细信息放入高级设置。
- 逆解：目标来源为当前 TCP、项目任务或手动目标；候选表列为序号、分支、关节变化、最小裕量、奇异性、碰撞、连续性、状态。支持筛选、三维预览和“用于规划”，不直接写回当前关节状态。
- 任务验证：任务表列为序号、任务、目标、可达、解数量、最小裕量、奇异性、碰撞、原因。区域表列为区域、样本数、可达数、覆盖率、最差裕量、状态。
- 能力探索：工作空间支持随机采样和网格采样，常用字段为采样方式、样本数；随机种子和网格步长进入高级设置。姿态覆盖支持项目目标或手动目标、方向数和滚转数。
- 二维图：数据来源、投影平面、着色指标、点云和近似包络、筛选条件。包络必须标注为近似，仅用于探索预览。

导出只提供工程师可理解的表格、图像和报告内容。

## 8. 轨迹界面

左侧显示只读任务序列，中央为三维视图，右侧为当前段属性，底部提供轨迹段、位置、速度、加速度、碰撞、分支、诊断和播放控制。

轨迹段表列：序号、来源、起点/终点、类型、状态、开始时间、持续时间、最小裕量、碰撞、限位、原因。首批类型只包含关节运动、笛卡尔直线和停留，不展示尚未交付的圆弧或跃度功能。

常用设置：速度比例、加速度比例、平滑方式、碰撞策略、分支策略。低频求解细节进入高级设置。操作包括规划、重规划、取消、播放、暂停、逐段和定位问题。曲线与三维播放、轨迹段表同步定位。

空态提示“请先完成可达的任务定义”；失败时保留已完成的段，并在段表中显示首个失败原因和建议。

## 9. 动力学界面

顶部显示输入摘要并提供返回建模、需求或轨迹的快捷入口。默认呈现关节侧工程量，不混入未交付的电机侧或电气模型。

关节包络表列：关节、峰值转矩或推力、RMS、峰值速度、峰值加速度、峰值功率、能量、发生时刻、裕量、状态。右侧详情显示峰值工况、持续时间、主要贡献和数据可信度。曲线包括力/转矩、速度、加速度、功率、机械能和摩擦贡献。

统计口径默认为峰值窗口和全周期 RMS，并显示计算工况。数据来源标签使用“趋势参考”“工程计算”“外部对比”。数值求解细节放入高级设置，不显示实现类名。

## 10. 选型界面

左侧为各运动轴，中央三维视图突出当前关节，右侧为电机与减速器组合详情，底部为可行方案、淘汰方案、曲线、工作点、整机草案和诊断。

轴需求摘要显示峰值、RMS、速度、加速度、惯量和主要工况。默认筛选包括类型、安装尺寸、额定能力、峰值能力、速比范围和安全裕量；温升、寿命、环境修正等进入高级设置。

可行方案表列：排名、电机、减速器、速比、转矩裕量、速度裕量、惯量匹配、质量、成本、状态。淘汰表列：电机、减速器、实际值、要求值、淘汰原因。曲线显示能力边界和工作点，不外推未覆盖区域。

比较支持 2～4 个组合，按各指标并列，不生成综合总分。“选用”只把当前轴加入整机草案；所有轴完成后，“应用整机方案”一次形成新方案版本。产品目录使用名称和版本，不显示哈希、表名或内部格式。

## 11. 联合分层优化界面

顶部选择新机设计或改造设计，并选择静态评估或含关节优化。左侧定义变量、目标、约束和设置；中央显示 Pareto 结果和三维候选预览；右侧显示候选详情；底部显示候选表、比较、快速淘汰、稳健性、任务和诊断。

变量表列：变量、对象、类型、下限、上限、步长或候选集、启用、状态。只显示已批准的工程变量，不显示内部路径或任意对象标识。

目标表从八项指标中选择；默认使用节拍、质量、成本。选择五项及以上时提示结果解释难度。静态模式只显示可计算指标。约束分为硬约束、工程约束和偏好；安全与必须项不能降级。

候选表列：候选、可行性、尺寸包络、结构质量、节拍、正机械功、器件质量、器件成本、最小关节裕量、最小驱动裕量、状态，不提供加权总分。碰撞结论归硬约束，稳健性在独立结果页呈现。Pareto 图可选择横轴、纵轴、颜色和点大小，并使用“在当前变量范围和计算预算内发现”的准确表述。

操作：开始、暂停、继续、取消、继续上次、预览、加入比较、正式复核、设为当前方案。正式复核通过后，用户确认才形成新方案版本，并触发相关阶段重新计算。进度自动保存，但界面不显示内部任务标识。

## 12. 公共右侧与底部面板

### 12.1 对象属性

显示当前选中对象的名称、类型、所属阶段、关键参数和状态。字段按对象类型切换；只读结果与可编辑方案字段视觉上明确区分。

### 12.2 点动

提供关节/笛卡尔模式、坐标系、步长、速度比例、正负方向和回到命名姿态。点动只改变场景预览；写入姿态必须通过明确的“记录姿态”操作。

### 12.3 工程设置

标签页为通用、碰撞、运动学、轨迹、动力学、选型、优化。每项显示名称、当前值、单位、适用范围和恢复默认；高级项默认折叠。更改会使受影响结果标记为需重算。

### 12.4 场景显示

提供机器人、工具、环境、坐标系、轨迹、碰撞体、包络、标注的显示开关，以及透明度和选中高亮。显示变化立即生效且不改变方案。

### 12.5 任务

表列：任务、阶段、方式、状态、进度、已用时间、开始时间、操作。操作根据状态显示查看、取消或重试。

### 12.6 诊断

表列：级别、阶段、对象、问题、实际值、要求值、建议。双击或“定位”应抬升对应阶段 Dock、选中表格行并在三维视图高亮对象。

### 12.7 计算依据与报告

计算依据显示：方案版本、计算方式、模型摘要、需求摘要、主要设置、开始/完成时间、结论。报告对话框字段：报告名称、方案、包含内容、输出格式、保存位置。内容可选模型、需求、运动学、轨迹、动力学、选型、方案比较、假设和遗留问题；格式为 HTML，按需要附带 JSON 或 CSV 表格。

## 13. 空态与错误态

空态必须说明下一步，并只提供一个主要操作：

| 场景 | 提示 | 主要操作 |
|---|---|---|
| 无项目 | 新建或打开项目后开始设计 | 新建项目 |
| 建模为空 | 请先建立机器人结构 | 新增关节 |
| 需求为空 | 请添加首个关键工位 | 新增工位 |
| 运动学无目标 | 请从项目任务或三维场景选择目标 | 选择目标 |
| 轨迹无任务 | 请先完成可达的任务定义 | 前往需求 |
| 动力学无轨迹 | 请先生成有效轨迹 | 前往轨迹 |
| 选型无工况 | 请先完成动力学计算 | 前往动力学 |
| 优化无变量 | 请先选择优化变量 | 添加变量 |

字段问题行内显示；阶段问题进入诊断表；系统错误使用短横幅“操作未完成”，提供“重试”和“详情”。错误详情可包含技术信息，但默认折叠。用户输入失败时保留当前编辑内容；计算失败时保留输入和已经完成的中间结果，并明确其不可作为正式结论。

## 14. 一致性验收清单

文档写入完成后应逐项检查：

- 中央三维视图在所有关键页面中保持不变。
- 建模页面不包含 URDF 导入、模型导入、导入报告或独立模型检查。
- 七个阶段都定义入口、字段、操作、表格列、空态、错误态和关键线框图。
- 高频功能直接可见，低频功能进入高级设置或更多。
- 不出现面向实现的哈希、冻结、Schema、缓存、内部对象标识和运行编号。
- 不使用加权综合总分评价选型或优化候选。
- 需求、工程设置和上游结果不在下游页面重复编辑。
- 预览、点动和播放不修改方案；应用更改和采用方案才形成新版本。
- 结果状态、任务状态、按钮状态和诊断定位规则跨模块一致。
- 1920×1080、100%～150% 缩放下，主要工作无需横向滚动且三维视图保持可用。
