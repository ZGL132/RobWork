# 运动学审核修复与面板交互设计

## 目标

修复 WP-15-T20 审核发现的异步运动学求解会话污染、可变视图并发访问、异常不回调、覆盖结果配置摘要遗漏和 future 自引用泄漏；同时让运动学面板明确区分输入、求解中、结果有效和结果过期状态。

## 设计

### 运行时一致性

单点求解提交时从当前会话导出不可变运行时快照和值语义请求。后台任务只捕获 `shared_ptr<const IKinRuntimeView>`（或现有等价的不可变视图接口）和请求值，不再读取可 `rebind()` 的 `KinSessionModelView`。提交回执携带 `snapshotId`、`epoch` 和 `configDigest`。UI 回调只有在三者与当前会话完全一致时才允许写入结果；不一致时保留当前会话，状态行显示结果已过期并要求重新求解。

### 异步生命周期与错误

异步执行器将 `std::exception` 转成失败回执，成功和失败都经过同一个 UI 完成回调，因此在途标志必然清除。任务句柄由装配层持有，完成后释放；不通过 lambda 捕获承载 future 的 `shared_ptr`，避免引用环。执行器缺席时继续使用现有同步降级路径。

### 覆盖结果校验

覆盖结果投影除 `ok/epoch/snapshotId` 外还必须匹配 `configDigest`。配置提交、项目切换或会话重绑定时清空旧覆盖结果，并把结果摘要置为“需重新求解”，避免旧配置结果继续显示。

### 面板交互

位姿页按目标输入、当前上下文、求解操作和状态摘要分组。求解按钮在任务进行时禁用并显示忙碌状态；完成后显示成功或失败原因；身份不匹配时显示过期状态。单位切换、TCP 回填和配置变更只更新输入并明确提示需要重新求解。非法输入在对应字段附近反馈，避免只在底部状态行出现不可定位的错误。结果表沿用现有域投影，不添加业务判定。

## 验证

先增加失败测试覆盖：旧回调在项目切换后不写入、可变视图解绑期间任务使用冻结快照、异常后按钮恢复、覆盖结果拒绝错误配置摘要、异步任务句柄完成后可释放；再执行集成构建、独立构建、单元/契约测试和 Windows Qt GUI 测试。
